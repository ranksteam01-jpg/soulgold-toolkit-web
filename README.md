# SoulGold Personal Arcade · Collection v4.0.1

รุ่นย่อ: **คลังเกม / เล่นเกม / การเดินทาง** ไม่มี Studio, ROM Lab หรือหน้า Save Editor แยก

## เปิดและอัปโหลด

1. แตก ZIP แล้วใช้ไฟล์ **ข้างใน** โฟลเดอร์นี้ ไม่ต้องอัปโหลด ZIP หรือโฟลเดอร์ outputs ทั้งหมด
2. วาง `index.html` ไว้รากของเว็บไซต์ พร้อมไฟล์ CSS/JS, `modules/` และ `vendor/` โดยคงโครงสร้างเดิม ไม่ต้อง build หรือติดตั้ง WSL
3. เปิดผ่านเว็บ HTTPS (เช่น GitHub Pages) หรือเซิร์ฟเวอร์ localhost ไม่ใช้การดับเบิลคลิก HTML แบบ file://
4. ถ้าเว็บเดิมยังแสดงหน้าเก่า ให้สำรองเซฟ ปิดแท็บเล่นอื่น แล้วเปิด `update-play.html` บนที่อยู่เว็บเดิม

หากอัปเดต repo รุ่นเก่า การอัปโหลดทับอย่างเดียวจะไม่ลบไฟล์เก่า แนะนำสำรอง repo เก่าก่อน แล้วใช้ชุดนี้เป็นเนื้อหาเว็บชุดใหม่ ไม่ต้องแนบ assets/source, Studio หรือโฟลเดอร์เซิร์ฟเวอร์เดิม

## คอลเลกชัน

- เพิ่ม ROM GBA ที่คุณมีสิทธิ์ใช้งานได้หลายไฟล์ ระบบตรวจ header และแยกเกมด้วย SHA-256
- กดปกแล้วเปิดเกมอัตโนมัติ มีค้นหา รายการโปรด เรียงเกม ตั้งชื่อ และเปลี่ยนปก
- ปุ่ม “ถ่ายเป็นปก” ในหน้าเล่นใช้ภาพหน้าจอขณะนั้น หรือเลือก PNG/JPG/WebP เป็นปกเองในคลัง
- ไม่มี ROM, BIOS, ภาพ Pokémon, เซฟส่วนตัว หรือรหัสผ่านบรรจุในแพ็ก

## เพิ่มของ / สูตรจากหน้าเล่น

เปิดเกม SoulGold รุ่นที่ตรงโปรไฟล์ → ยืนยันรุ่นที่ Journey Link → กด **กระเป๋า / สูตร**

- เลือกไอเทม 929 รายการจาก 8 หมวด พร้อมช่องค้นหาและจำนวน รวมของเดิมสูงสุด 999
- สูตรสำเร็จ: ตั้งเงิน 999,999, ชุดฟื้นฟู, ชุดโปเกบอล
- **โหมดเซฟ (ค่าเริ่มต้น):** ต้อง Save ในเมนูเกมก่อน ระบบสำรองจุดปัจจุบัน แก้ .sav แล้วปิดหน้ากระเป๋า รีและเปิดตัวเกมให้อัตโนมัติ ไม่ต้องกดปิดหน้าต่างหรือปุ่มเล่นต่อของเว็บอีก แต่ยังต้องผ่านหน้าไตเติลและเลือก Continue ภายในเกมเอง เพราะยังไม่มีตัวตรวจเมนูของ ROM รุ่นนี้ ความคืบหน้าหลัง Save ล่าสุดจะไม่อยู่ใน .sav นั้น หากสลับไปแท็บอื่นระหว่างแก้ ระบบจะยังพักเกมไว้
- **โหมดสด:** ต้องแนบ .map/.sym ที่ build จาก ROM ไฟล์เดียวกันก่อน โปรแกรมตรวจ state รุ่น, RAM pointer, ตัวผู้เล่น และ encryption key ก่อนแก้ข้อมูลใน RAM ไม่เดาตำแหน่งจากชื่อไฟล์ อยู่บนแผนที่และปิดกระเป๋า ร้านค้า และการต่อสู้ในเกมก่อนใช้ เมื่อสำเร็จเว็บปิดหน้ากระเป๋าและเล่นต่อเอง จากนั้นเปิดกระเป๋าในเกมใหม่และ Save ในเกมเพื่อให้ไอเทมติดใน .sav
- มีจุดสำรอง “ก่อนใช้สูตร” แยกจากเซฟอัตโนมัติ และปุ่มย้อนกลับ / ดาวน์โหลดสำรอง
- ไอเทมสำคัญไม่ได้ทำให้ภารกิจสำเร็จ ไม่แก้ flags หรือปลดล็อกเนื้อเรื่องให้เอง
- **ไม่ใช่สูตรสากลทุกเกม GBA** เกมอื่นเล่นได้ แต่ไม่มีการฉีดไอเทมหรือสูตรสำหรับเกมอื่นในรุ่นนี้ และไม่รองรับ HeartGold/SoulSilver บน DS

## เซฟและย้ายเครื่อง

- บันทึกจุดเล่นต่อทุก 8 วินาทีขณะเล่น + ก่อนกดออก ไม่รับประกันวินาทีสุดท้ายหากระบบปิดเบราว์เซอร์ทันที
- `.sgsave` คือจุดเล่นต่อใน emulator นี้ ส่วน `.sav` คือการบันทึกจากเมนูเกม
- ย้ายเครื่อง: ดาวน์โหลด .sgsave → อีกเครื่องเปิด ROM เดียวกัน → นำเข้าเซฟ
- **ยังไม่มี Cloud Sync ข้ามเครื่อง** เซฟ/ROM/ปกอยู่ในเบราว์เซอร์เครื่องนี้ ไม่ส่งขึ้น GitHub
- ฐานข้อมูลยังใช้ `soulgold-play-v1` และข้อมูลคู่มือใช้ key เดิม ไม่ล้างเซฟของรุ่นก่อน แต่เปลี่ยนโดเมน/พอร์ต/เบราว์เซอร์จะเป็นคนละพื้นที่เก็บข้อมูล ต้องย้ายด้วยไฟล์สำรอง

## ขอบเขตการทดสอบ

ตรวจการเพิ่มของครบทุก ID, หมวดกระเป๋า, XOR, checksum, เซฟสอง slot, counter rollover, การปฏิเสธข้อมูลผิดรูปแบบ และการไม่แตะข้อมูล PC/เนื้อเรื่อง ทดสอบ mGBA WASM จริงกับโปรแกรม GBA ที่เขียนขึ้นสำหรับทดสอบและบล็อกเซฟจำลอง รวมถึงเร่ง 2×/4× และโหลด RAM ที่แก้แล้ว

ทดสอบผ่านหน้าเว็บจริง: เพิ่มเกม → กดปกเข้าเกม → เพิ่ม Potion → สูตรเงิน → ย้อนก่อนแก้ → ถ่ายภาพปก → บันทึกออกคลัง; คู่มือเปิดได้และไม่โหลดภาพ Pokémon ตรวจโครงสร้างหน้าจอคอม/มือถือโดยไม่มีการล้นแนวนอนในหน้าคลัง

**ยังไม่ได้ยืนยันโหมดสดกับ ROM ส่วนตัวของคุณ หรือทดสอบมือถือจริงทุกเครื่อง** หากไม่มี symbols ตรงรุ่น ใช้โหมดเซฟก่อนและเก็บไฟล์สำรองไว้
